# Supportka

Плагин для [Vencord](https://github.com/Vendicated/Vencord), созданный специально для саппорт-состава сервера [Lounge](https://discord.com/invite/dxrjJ4qbQ8).

**Supportka** объединяет основные инструменты саппорта в одном интерфейсе: управление пользователями, быстрый вход в голосовые комнаты, автоматическую проверку профилей, систему меток и встроенную памятку.

Плагин поддерживает работу **с двух аккаунтов** — саппорт-аккаунта и аккаунта контроллера. Контроллер может отправлять команды, а саппорт-аккаунт выполняет их непосредственно на сервере.

## Возможности

### 👤 Управление пользователями

При открытии профиля пользователя появляются дополнительные кнопки для быстрого выполнения основных действий:

* **Мьют / Размьют** — серверный мьют пользователя в голосовых каналах.
* **Мальчик** — отправляет ID пользователя в соответствующий канал.
* **Девочка** — отправляет ID пользователя в соответствующий канал.
* **Отказ** — открывает окно для указания причины отказа и отправляет информацию в канал отказов.
* **Быстрые причины** — заранее настроенные пресеты для наиболее частых причин отказа.

Все действия выполняются непосредственно из попапа профиля, без необходимости вручную искать каналы или копировать ID пользователя.

### 📖 Памятка саппорта

В плагин встроена интерактивная **памятка саппорта** — отдельное плавающее окно, которое можно перемещать и изменять по размеру.

В ней можно хранить:

* инструкции по работе с тикетами;
* ответы на частые вопросы;
* правила и важную информацию;
* запрещённую символику с изображениями;
* чек-лист проверки профиля;
* любые дополнительные инструкции для саппорт-состава.

Памятка открывается прямо из верхней панели Discord, а её содержимое можно редактировать через настройки плагина.
## Автообновление

Обновления распространяются через встроенный **Vencord Updater**.

При запуске Vencord проверяет последний релиз репозитория `Braqden/Vencord-Supportka` и сравнивает его версию с установленной. Если есть новая версия — появится уведомление **«A Vencord update is available!»**. При переходе во вкладку **Updater** (или с включённой настройкой `autoUpdate` — без участия пользователя) новые файлы скачаются в папку `dist`, после чего останется лишь перезапустить Discord.

Пользователю **ничего настраивать не нужно** — достаточно один раз поставить свежую версию.

### Как выпустить новую версию

1. Внеси изменения в `src/plugins/supportka`.
2. Запусти `release.bat` и введи новый тег версии (например `v2.0.2`). Скрипт пересоберёт плагин, обновит локальную установку, закоммитит и запушит тег.
3. GitHub Actions соберёт релиз автоматически и прикрепит файлы (`renderer.js`, `renderer.css`, `preload.js`, `patcher.js`).
4. Все пользователи получат обновление через Vencord Updater.

> ⚠️ Сборку всегда нужно делать с тегом версии, иначе клиенты будут считать установленную версию актуальной или обновятся на ванильный Vencord.
