# Vencord-Supportka

Плагин для [Vencord](https://github.com/Vendicated/Vencord), созданный специально для Lounge и помогающий саппорт-составу.

## Возможности

- **Кнопки в профиле пользователя**: Замутить/Размутить (серверный мьют), Мальчик, Девочка, Отказ с причиной.
- **Управление через друга**: аккаунт саппорт-состава может выполнять команды, отправленные другом через релей-канал (JSON-команды).
- **Авто-проверка профиля** по чек-листу: Имя, Глобальное имя, Статус, Обо мне, Местоимения. Проверяются сексуальный контент, ориентация, наркотики, нацизм, суицид/селфхарм, дискриминация, оскорбления, ссылки (с учётом спойлеров), реквизиты/продажа, запрещённые имена.
- **Метки**: принятые и отклонённые пользователи помечаются в профиле (зелёная/красная метка), хранятся локально.
- **Настраиваемые списки**: свои запрещённые слова, разрешённые и запрещённые ссылки, пресеты причин отказа — всё настраивается в настройках плагина без пересборки.

## Установка у себя

1. Скопируйте папку `src/plugins/supportka` в папку `src/plugins` исходников вашего Vencord.
2. Соберите и установите Vencord как обычно:

   ```sh
   pnpm i
   pnpm build
   pnpm inject
   ```

   (если интерактивный `pnpm inject` не работает — выполните `node scripts/runInstaller.mjs -- --install -branch stable`)
3. Перезапустите Discord (полностью, через трей → Quit).

## Быстая установка

Достаточно:

1. Установить [Git](https://git-scm.com/download/win), [Node.js LTS](https://nodejs.org) и pnpm (`npm i -g pnpm`).
2. Скачать этот репозиторий (Code → Download ZIP) и распаковать.
3. Запустить **двойным кликом** `install.bat` и дождаться завершения (само соберёт Vencord и установит плагин).
4. Полностью перезапустить Discord (трей → Quit) и включить плагин.

В настройках плагина нужно нажать выполнение команд

## Настройка

В настройках плагина (Discord → Vencord → Plugins → supportka):

| Настройка | Назначение |
| --- | --- |
| relayChannelId | Канал, в который отправляются JSON-команды (релей-канал) |
| controllerId | ID друга, чьи команды нужно выполнять |
| Отправлять команды | Отправлять команды в релей-канал вместо выполнения (аккаунт друга) |
| Выполнять команды | Слушать релей-канал и выполнять команды от друга (саппорт-аккаунт) |
| Проверять профиль | Показывать результат авто-проверки профиля в попапе |
| Отмечать принятых | Авто-метка «Принят» при нажатии Мальчик/Девочка и «Отклонён» при Отказе |
| Пресеты причин отказа | Быстрые причины в окне «Отказ», разделяются `;` |
| Доп. запрещённые слова | Слова/фразы, которые считать нарушением (красный), через `;` |
| Разрешённые ссылки | Доп. домены/ключевые слова ссылок, которые не считаются нарушением, через `;` |
| Ссылки для удаления | Доп. домены ссылок, которые нужно убрать полностью (красный), через `;` |

## Формат команды

```json
{"type":"vc-supportka","action":"boy|girl|mute|unmute|reject","user":"<ID>","guild":"<ID>","reason":"<причина>"}
```
