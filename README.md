# Supportka

Плагин для [Vencord](https://github.com/Vendicated/Vencord), созданный специально для саппорт-состава сервера [Lounge](https://discord.com/invite/dxrjJ4qbQ8).

**Supportka** объединяет основные инструменты саппорта в одном интерфейсе: управление пользователями и встроенную памятку.

# [Скачать](https://github.com/Braqden/Vencord-Supportka/releases)
Скачиваешь ZIP файл, запускаешь drop-in.bat перезапускаешь дискорд (Обязательно скачай Vencord, Vesktop и другие программы работающие через Vencord)
