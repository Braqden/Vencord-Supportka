# Саппорта

Плагин для [Vencord](https://github.com/Vendicated/Vencord), созданный специально для [Lounge](https://discord.com/invite/dxrjJ4qbQ8) и помогающий саппорт-составу.

## Возможности

- Быстро принимать пользователей, при открытии профиля пользователя у вас появляться кнопки с Мьют/Размьют , Мальчик , Девочка и Отказ.
- **Кнопка Мальчик** - отправляет ID пользователя в канал пропуска.
- **Кнопка Девочка** - отправляет ID пользователя сначала в женский канал, после чего в канал пропуска.
- **Кнопка Отказ** - открывает у вас форму где нужно написать причину отказа, после чего ID с причиной отправляется в отказа, с ID и причиной.
- **Кнопка Мьют/Размьют** меняется в зависимости в мьюте пользователь или нет.
